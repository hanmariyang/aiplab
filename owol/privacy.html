개인정보처리방침

2026년 10월 5일 기준

오월의 개발자(인스타그램 @owol.dev, 이하 「저」)가 운영하는 이 웹 페이지(aiplab.kr/owol)와 인스타그램 댓글 자동 답장에서 어떤 정보를 어떻게 다루는지 적어 둡니다.

1. 웹 페이지

  • 쿠키를 쓰지 않아요.
  • 방문 기록으로 페이지 주소, 들어온 곳(리퍼러), 브라우저 정보를 남겨요. IP 주소는 그대로 저장하지 않고, 하루마다 바뀌는 값으로 섞어 되돌릴 수 없는 형태로만 남겨요.
  • 가이드에 적은 세 칸 입력과 체크 표시는 방문하신 기기의 브라우저에만 저장되고 저에게 오지 않아요.
  • 목적: 몇 명이 어디서 들어와 어디까지 봤는지 세기 위해서예요.

2. 인스타그램 댓글 자동 답장

  • 제 게시물에 정해 둔 단어(예: 「가이드」)로 댓글을 남기시면, 요청하신 자료 링크를 인스타그램 메시지로 한 번 보내 드려요.
  • 이때 Meta 의 공식 Instagram API 로 다음을 받아요: 댓글 ID, 댓글 내용, 인스타그램 사용자 이름과 ID, 댓글 시각.
  • 쓰는 곳: 메시지를 보내고, 같은 분께 두 번 보내지 않도록 확인하는 데만 써요. 광고, 분석용 프로필 만들기, 다른 곳에 넘기기에 쓰지 않아요.
  • 보관: 보낸 뒤 90일이 지나면 지워요.
  • 제 계정이 아닌 다른 계정의 댓글이나 메시지는 읽지 않아요.

3. 맡기는 곳

  • 서버와 데이터베이스는 Railway(미국)에서 돌아가요.
  • 인스타그램 메시지는 Meta 를 통해 보내져요. Meta 의 처리 방식은 Meta 개인정보처리방침을 따라요.

4. 지워 달라고 하기

언제든 지워 달라고 하실 수 있어요. 방법은 데이터 삭제 안내에 있어요.
