첫 앱 7일 가이드

제가 혼자 AI랑 앱 열 개를 내면서 쓴 순서를, 처음 만드는 분에게 제일 쉬운 길로 다시 맞췄어요. 하루에 한 칸씩, 하루에 하나만 하세요.

약속하는 것
7일 뒤에 남에게 링크를 보낼 수 있는 물건이 하나 생겨요.
약속 안 하는 것
앱스토어 통과, 사용자, 돈. 그건 그다음 이야기예요.

7일이 다 같은 무게는 아니에요. 3일차와 5일차는 나머지보다 무거워서 이틀이 걸릴 수 있어요. 그건 정상이고, 못하는 게 아니에요. 칸을 건너뛰지만 않으면 돼요.

체크와 입력은 이 기기에만 남아요. 어디로도 보내지 않아요.

시작 전에 · 세 칸만 채워요

빈칸을 말로 채워 보세요. 못 채우면 아직 만들 때가 아니에요.

세 번째 칸이 제일 중요해요. 지금 하는 방법보다 편하지 않으면 아무도 안 써요. 나조차도요.

갈림길 하나 · 웹이냐 앱이냐

시작하기 전에 이것만 골라요. 되돌리기 어려운 유일한 선택이에요.

웹앱
남에게 보여주기링크 하나설치 · 심사 · 계정
돈0원으로 시작애플·구글 등록비
첫 화면까지몇 시간며칠
카메라·알림·오프라인제한 있음돼요
고치기올리면 바로심사를 다시 받아요

거의 다 웹으로 시작하는 게 맞아요. 꼭 앱이어야 하는 건 셋 중 하나일 때예요. 알림을 보내야 할 때, 카메라나 센서를 써야 할 때, 인터넷 없이 써야 할 때.

아니라면 웹으로 만들고, 사람이 붙은 뒤에 앱으로 가요. 앱부터 시작해서 그만두는 사람이 웹으로 시작해서 그만두는 사람보다 훨씬 많아요.

오늘 하나만들 것을 한 문장으로 써요.

문장이 길어지면 만들다가 길을 잃어요. 짧으면 막혔을 때 돌아올 자리가 생겨요.

AI에게 이렇게
이런 걸 만들려고 해: ""
기능을 늘리지 말고, 이걸 한 문장으로 줄여줘.
그리고 이 한 문장에 꼭 필요하지 않은 걸 다 골라서 빼줘.
다 됐는지 확인
막히면 · 기능이 자꾸 붙어요「지금 안 만들 것」 목록을 따로 적어 두세요. 지우는 게 아니라 미루는 거라 마음이 편해져요.
오늘 하나종이든 화면이든 세 장만 그려요. 처음 보는 화면, 무언가 하는 화면, 결과 화면.

코드보다 그림이 훨씬 빨리 고쳐져요. 여기서 고치는 게 제일 싸요.

AI에게 이렇게
이 앱의 화면 세 장을 HTML 한 파일로 만들어줘. 실제로 도는 코드 말고 그림만.
버튼을 눌러도 아무 일 안 일어나도 돼. 한 파일이어야 하고 브라우저로 바로 열려야 해.
다 됐는지 확인
막히면 · 예쁘게 안 나와요지금은 예쁠 필요가 없어요. 자리만 맞으면 넘어가요. 색과 글꼴은 6일차에 한 번에 손대요.
오늘 하나내 컴퓨터에서 빈 화면 하나가 뜨게 해요.

여기서 제일 많이 포기해요. 그래서 오늘은 아무 기능도 안 만들어요. 빈 화면에 내 이름이 뜨면 그걸로 성공이에요.

AI에게 이렇게
내 컴퓨터는 야. 을 만들려고 해.
지금 깔아야 하는 걸 순서대로 알려줘. 이유는 짧게.
다 깔았는지 확인하는 명령도 같이 줘. 한 번에 한 단계씩 알려줘.
다 됐는지 확인
막히면 · 에러가 나와요에러 메시지를 통째로 붙여 넣고 물어보세요. 요약하지 마세요. 줄여 쓰면 엉뚱한 답이 와요. 처음 만드는 분이 제일 자주 손해 보는 자리예요.

되돌리는 법 · 오늘 같이 외워요

망가뜨릴 용기가 있어야 빨리 늘어요. 이 넷이면 돼요.

git init                                  # 맨 처음 한 번
git add -A && git commit -m "되는 상태"    # 될 때마다. 자주.
git status                                # 망했을 때: 뭐가 바뀌었는지 먼저 봐요
git restore .                             # 그다음: 마지막 커밋으로 되돌려요

되면 무조건 커밋하세요. 하루에 열 번도 좋아요. 공짜예요.

되돌려요
마지막 커밋 뒤에 고친 파일
안 건드려요
새로 만든 파일. 그대로 남아서 반쯤 되돌아간 상태가 돼요
못 해요
이미 커밋한 것. 그때는 AI에게 「직전 커밋으로 돌아가고 싶어」라고 물어보세요
조심
되돌린 작업은 영영 사라져요. 묻지 않고 지워요

하나 더 · 사본을 다른 데 둬요

커밋은 전부 이 컴퓨터 안에만 있어요. 노트북이 고장 나거나 폴더를 실수로 지우면 7일이 통째로 사라져요. 실제로 흔한 사고예요. GitHub에 비공개 저장소를 하나 만들어 올려 두세요. 무료이고, 한 번 이어 두면 그다음부터는 git push 한 줄이에요.

AI에게 이렇게
이 폴더를 내 GitHub 비공개 저장소에 올려 줘. 처음이라 계정 연결부터 알려줘.
오늘 하나내 컴퓨터가 아니라 실제로 쓸 물건에 띄워요.

7일 중 제일 중요한 날이에요. 여기서 안 되는 건 나중엔 더 안 돼요. 컴퓨터에서 예뻤던 게 폰에서 깨지는 걸 오늘 보는 게 나아요.

AI에게 이렇게
지금 만든 걸 내 폰에서 열어 보고 싶어. 내 폰은 야.
가장 간단한 방법 하나만 골라서 한 단계씩 알려줘.
폰에서 진짜 열렸는지 확인하는 방법도 같이.
다 됐는지 확인
막히면 · 웹인데 폰에서 안 열려요① 같은 와이파이인지 ② 주소를 localhost가 아니라 컴퓨터 주소로 열었는지 ③ 서버가 localhost에만 묶여 있지 않은지 봐요. 셋째라면 AI에게 「폰에서 열리게 서버를 밖으로 열어 줘」라고 하세요.
막히면 · 앱인데 안 깔려요오늘은 시뮬레이터(가짜 폰)로 넘어가도 돼요. 다만 가짜 폰에서 된 건 진짜 폰에서 된다는 증거가 아니에요. 나중에 꼭 진짜 폰에서 보세요.
오늘 하나넣고, 저장되고, 다시 열어도 남아 있어요. 이 한 바퀴를 완성해요.

여기까지 오면 쓸 수 있는 물건이 돼요. 기능이 하나뿐이어도요.

AI에게 이렇게
사용자가 을 입력하면 저장되고, 앱을 껐다 켜도 남아 있게 해줘.
서버랑 로그인은 아직 만들지 마. 이 기기 안에만 저장하면 돼.
비어 있을 때 화면이랑, 잘못 입력했을 때 화면도 같이 만들어줘.

로그인과 서버를 미루는 게 처음 만들 때 가장 큰 절약이에요. 둘은 난이도가 갑자기 뛰어요. 「이 기기 안에만 저장」으로 시작하면 며칠 걸릴 일이 몇 시간이 돼요.

다 됐는지 확인
막히면 · 저장이 안 돼요「저장됐어요」 표시만 뜨고 실제로는 화면에만 있는 경우가 흔해요. 껐다 켜서 확인하지 않으면 몰라요.
오늘 하나이름, 아이콘, 색. 오늘 하루만 꾸며요.

기능이 도는 걸 보고 꾸며야 해요. 먼저 꾸미면 버리게 돼요.

AI에게 이렇게
색을 두 개로 줄이고 여백을 정리해줘. 기능은 건드리지 마.
그리고 아이콘을 만들어줘. 아주 작게 줄여도 뭔지 알아볼 수 있게, 단순하게.
다 됐는지 확인
막히면 · 디자인이 마음에 안 들어요좋아하는 앱 화면을 찍어서 보여 주고 「이 느낌으로 색과 여백만 맞춰 줘」라고 하세요. 처음부터 말로 설명하려 하지 마세요.
오늘 하나남이 열 수 있는 주소를 만들어요.

웹이면 어디에 올릴지는 내 프로젝트가 둘 중 어느 쪽인지에 따라 갈려요. 서비스 이름은 해마다 바뀌어도 이 갈림은 안 바뀌어요.

파일만 있어요브라우저로 index.html을 직접 열어도 돌아가요쉬워요. 무료로 올려 주는 곳이 많아요
서버가 돌아요npm start 같은 걸 켜 둬야 돌아가요한 단계 더 있어요. 켜 둘 곳이 필요해요
AI에게 이렇게
내 프로젝트는 . 무료로 인터넷에 올리고 싶어.
지금 쓸 수 있는 곳을 알려주고 가장 간단한 걸로 한 단계씩.
올린 뒤에 주소가 진짜 되는지 확인하는 법도 같이.

무료 등급은 한동안 안 쓰면 잠드는 곳이 있어요. 링크를 받은 사람이 처음 열 때 몇 초 걸릴 수 있어요. 고장이 아니에요. 앱이라면 오늘 스토어에 내지 않아요. 먼저 테스트 배포(TestFlight, 내부 테스트)로 보내요. 심사 없이 친구 몇 명이 받아 볼 수 있어요. 스토어는 그다음이에요.

다 됐는지 확인
막히면 · 내 컴퓨터에선 되는데 올리면 안 돼요거의 늘 설정 차이예요. 「내 컴퓨터에선 되는데 올리니까 <증상>. 뭘 확인해야 해?」라고 증상 그대로 물어보세요.

올리기 전에 하나 · 열쇠가 코드에 있나요

어딘가에 가입해서 받은 키(sk-..., AIza... 같은 긴 글자)를 소스에 그대로 적어 두면 올리는 순간 남이 볼 수 있어요. 처음 만드는 분이 가장 비싸게 치르는 사고예요. 남이 내 키로 쓴 만큼 내 카드에서 돈이 나가고, 계정이 잠겨요.

AI에게 이렇게
내 코드에 API 키나 비밀번호가 적힌 곳이 있는지 다 찾아줘.
있으면 .env 로 옮기고 .gitignore 에 넣어줘. 이미 커밋에 들어갔는지도 확인해줘.

한 번 올라간 키는 지워도 늦어요. 저장소에서 지워도 기록에 남아요. 그럴 땐 파일만 고치지 말고 그 키를 버리고 새로 발급받으세요.

결제부터 넣기결제 없이 유료 화면만 켜 두면 심사에서 떨어져요대신 · 팔 게 생긴 뒤에

「됐다」고 착각하는 여섯 자리

전부 실제로 자주 일어나요.

AI가 「다 됐습니다」직접 열어 보세요. 예외 없어요
화면에 보여요저장된 건 아니에요. 껐다 켜 보세요
가짜 폰에서 돼요내 폰에서 되는 건 아니에요. 카메라·센서·알림은 특히요
내 폰에서 돼요남의 폰은 기종·글자 크기·다크 모드가 달라요
내가 쓰면 돼요처음 여는 사람은 데이터가 없어요. 앱을 지우고 다시 깔거나 시크릿 창으로 열어 보세요

  3. 심사에 냈다

앱은 이 넷이 전부 다른 상태예요. 말할 때 넷 중 어느 칸인지 골라서 말하세요. 「배포했다」는 넷을 뭉갠 말이라 저는 안 써요.

7일이 끝나면

물건 하나와, 그걸 고칠 수 있는 손이 생겼어요. 다음은 기능 추가가 아니에요.

  1. 한 사람에게 실제로 써 보게 해요. 옆에서 보되 설명하지 마세요. 막히는 자리가 고칠 자리예요
  2. 거기 하나만 고쳐요
  3. 다시 보여 줘요
