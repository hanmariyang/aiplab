AI가 「다 됐습니다」 하면
보내는 문장 5개

앱 10개를 혼자 AI랑 내면서 매번 쓰는 문장이에요. 복사해서 그대로 붙여 넣으면 돼요.

1 · 나눠 적게 하기

「다 됐습니다」를 들을 때마다. 이게 그 한 줄이에요.

AI에게 이렇게
방금 한 것 중에 직접 돌려서 확인한 것과
확인 못 한 것을 나눠서 적어줘.
확인 못 한 걸 됐다고 쓰지 마.
2 · 증거 붙이게 하기

「확인했어요」라는 말만 있고 무엇을 돌렸는지 안 보일 때.

AI에게 이렇게
확인했다고 한 것마다, 실제로 돌린 명령과
결과 마지막 몇 줄을 그대로 붙여줘. 요약하지 마.
3 · 숫자로 말하게 하기

「테스트 통과」라고만 할 때. 0개가 돌아도 통과처럼 보일 수 있어요.

AI에게 이렇게
테스트가 몇 개 돌았고 몇 개 통과했는지 숫자로 알려줘.
하나도 안 돌았으면 0개라고 써줘.
4 · 처음 여는 사람으로 보게 하기

내 화면엔 이미 데이터가 있어서 처음 쓰는 사람이 보는 화면을 놓쳐요.

AI에게 이렇게
데이터가 하나도 없는 처음 상태로 다시 열어 봐줘.
그때 화면에 무엇이 보이는지, 막히는 데가 있는지 알려줘.
5 · 어디까지 왔는지 한 칸으로

「배포했어요」가 만들었다는 건지, 사람들이 받을 수 있다는 건지 모를 때.

AI에게 이렇게
지금 어디까지 왔는지 이 넷 중 하나로만 말해줘.
만들었다 / 올렸다 / 심사에 냈다 / 사람들이 받을 수 있다

매번 치기 귀찮으면

규칙 파일(Claude Code 는 CLAUDE.md, Codex 는 AGENTS.md, Cursor 는 프로젝트 규칙)에 한 번 넣어 두면 매번 안 보내도 돼요.

규칙 파일에 넣기
# 보고 규칙
- 일을 끝냈다고 말하기 전에, 직접 돌려서 확인한 것과 확인 못 한 것을 나눠 적는다.
- 확인 못 한 것은 「확인 못 함」이라고 쓰고 이유를 한 줄 붙인다. 됐을 거라고 짐작해서 쓰지 않는다.
- 확인한 것에는 실제로 돌린 명령과 결과를 붙인다.
- 테스트는 몇 개 돌았고 몇 개 통과했는지 숫자로 쓴다. 0개면 0개라고 쓴다.
- 진행 상태는 「만들었다 / 올렸다 / 심사에 냈다 / 사람들이 받을 수 있다」 중 하나로만 말한다.

이 문장들은 AI를 정직하게 만들 뿐, 대신 확인해 주지는 않아요. 「확인 못 함」에 적힌 것부터 직접 열어 보세요.
